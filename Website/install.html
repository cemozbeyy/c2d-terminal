Install C2D Terminal

C2D Terminal has no signed or notarized download yet. Today you build it from source, which takes a few minutes on a Mac with Xcode installed.

A signed download needs an Apple Developer ID, which is in progress. Star or watch the repo to hear when it ships.

Requirements

  • macOS 15 or later on Apple Silicon.
  • Xcode with Swift 6.1 or later.
  • XcodeGen.
  • Claude Code, if you want agent sessions.

Install XcodeGen with Homebrew:

brew install xcodegen

Build and run

git clone https://github.com/cemozbeyy/c2d-terminal.git
cd c2d-terminal
./Scripts/run-debug.sh

The script generates the Xcode project, builds the Debug app and launches it. To open a project straight away:

./Scripts/run-debug.sh /path/to/project

Manual build

The Xcode project is generated from project.yml and is not committed. Generate it, then build:

xcodegen generate
xcodebuild build -project C2DTerminal.xcodeproj -scheme C2DTerminal -configuration Debug -destination 'platform=macOS' -skipPackagePluginValidation -skipMacroValidation

Or open C2DTerminal.xcodeproj in Xcode and press Run.

Release package

./Scripts/build-release.sh

This writes build/C2DTerminal.app and an unsigned zip. The app is ad-hoc signed, so Gatekeeper will refuse it on other Macs until it is signed with a Developer ID.

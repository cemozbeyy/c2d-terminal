Changelog

What changed in C2D Terminal, newest first. There are no versioned releases yet; every change lands on the main branch.

Week of 26 October 2026

  • Explorer and Source Control share one switchable side panel, with Git status colours in the file tree.
  • Token Saver: one combined usage report.
  • Editor tabs no longer clash with the side panel.

Week of 19 October 2026

  • Pages: keep several projects open in one window and switch between them.
  • Terminal windows with native tabs and split panes, listed in the page menu.
  • Git: VS Code-style change actions, file history, branch and sync controls in the status bar, "Commit all", and commit messages drafted by Claude Code.
  • Source Control diffs open as editor tabs.
  • Token Saver: token usage per project and session, read from Claude Code's local transcripts.
  • Fixes: terminals no longer go blank when switching tabs; resizing a pane now reaches Claude Code, so it redraws at the new size; quitting and removing a project close every open page.
  • The source code went public under the MIT license.

Week of 12 October 2026

  • Command palette also opens with ⌘P, next to ⌘K.
  • Git Fetch, Pull and Push are separate, explicit actions.
  • Terminal scrollback raised to 10,000 lines.
  • Closing a terminal ends its whole session, not just the shell.
  • Theme switching at runtime, and a one-command local launch script.

Try C2D Terminal

A free, open-source macOS app where Claude Code runs in a real terminal next to an editor and a Git panel. Nothing is committed or pushed until you press the button.

Install guide

Apple Silicon, macOS 15+. No signed download yet: you build it with Xcode. Star or watch the repo to hear when the signed release ships.

Philosophy

Agents propose. You inspect. You decide.

The rule behind every agent integration: no change is accepted, committed or pushed because an agent said it was done.

01 · Session

An agent works in a real PTY

Rooted at the project directory you chose. Its output and process state are shown as they are, never summarized into "thinking…".

zsh · Running · pid 47545 · started in ~/myprojects/c2d-terminal
02 · Review

Its changes land in Git, not in your trust

Changed files appear in the Changes panel with diffs and hunks, right next to the editor.

CHANGES 9 · Stage all · Select a file to see its diff
03 · Decide

You run tests, then commit

Approvals, commits and pushes are explicit actions. The terminal that runs your test suite is the same terminal, so the evidence sits next to the claim.

swift test --package-path Packages/C2DCore → 160 tests passed
Terminal-first

Real shell compatibility is the foundation, not a feature.

Truthful state

Unknown, running, failed and done are never conflated.

Local-first

No C2D cloud is required. Source stays on your machine.

Bring your own access

Use your own provider accounts. C2D does not resell tokens.

FAQ

Questions developers ask first

Is it a real terminal or a chat window?

A real terminal. Every shell and agent runs in a genuine PTY session with your own shell config and PATH. Interactive CLIs work as they do in Terminal.app.

Which agents are supported?

Claude Code today. C2D detects the installed binary and version and runs it in a session it owns. OpenAI Codex and other CLI agents follow through adapters; C2D never pretends they share one API.

Does my code leave my machine?

Not to C2D. Core development needs no C2D cloud service. Agents talk to the provider you configured with your own access, and you are responsible for those charges.

Will an agent commit or push for me?

No. Commits, pushes, pulls and discards are explicit actions in the Git panel. An agent finishing a task never changes your repository state on its own.

What are the requirements?

macOS 15 or later. Built in Swift with SwiftUI and AppKit. Signed and notarized builds outside the Mac App Store are planned.

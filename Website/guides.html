Claude Code guides for Mac

Short, practical guides for working with Claude Code on macOS. Each one works in any terminal, and notes where C2D Terminal does the same thing for you.

  • Review Claude Code changes before you commitKeep Claude Code from committing on its own, then read the diff, stage hunk by hunk and commit yourself.
  • Run several Claude Code sessions on a MacGive each session its own git worktree so parallel edits never collide, and keep track of which agent changed what.
  • Terminals for Claude Code on macOSClaude Code runs in any Mac terminal. What to set up in Terminal.app, iTerm2, Ghostty, Kitty, WezTerm and Warp.
  • Install C2D TerminalBuild the app from source with Xcode and XcodeGen.

Try C2D Terminal

A free, open-source macOS app where Claude Code runs in a real terminal next to an editor and a Git panel. Nothing is committed or pushed until you press the button.

Install guide

Apple Silicon, macOS 15+. No signed download yet: you build it with Xcode. Watch the repo for releases (Watch → Custom → Releases) to hear when the signed build ships.

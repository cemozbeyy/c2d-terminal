Choosing and setting up a terminal for Claude Code on macOS

Claude Code works in any terminal without configuration. The differences between terminals show up in three places: Shift+Enter for multi-line prompts, Option-key shortcuts, and notifications when a long task finishes. Here is what each common Mac terminal needs.

Updated 29 October 2026 · Written by the makers of C2D Terminal, which is one of the apps below. Setup details come from Anthropic's terminal configuration docs.

In every terminal, Ctrl+J or typing \ then Enter also inserts a newline. To get a bell where notifications are not supported, add this to ~/.claude/settings.json:

{ "preferredNotifChannel": "terminal_bell" }

Terminal.app

Ships with macOS. For Option-key shortcuts such as Option+P, open Settings → Profiles → Keyboard and check "Use Option as Meta Key". If you accepted Claude Code's first-run terminal setup, this is already done.

iTerm2

A free, open-source terminal for macOS (iterm2.com). For Option shortcuts, set Left and Right Option key to "Esc+" under Settings → Profiles → Keys → General. For notifications, go to Settings → Profiles → Terminal, check "Notification Center Alerts", then under "Filter Alerts" enable "Send escape sequence-generated alerts". Running /terminal-setup in iTerm2 lets Claude Code's /copy command reach your clipboard.

Ghostty

A free, open-source terminal with a native macOS interface (ghostty.org). Shift+Enter and notifications work without setup. For Option shortcuts, look for the Option-as-Alt setting in Ghostty's config file.

Kitty

A free, open-source, cross-platform terminal (sw.kovidgoyal.net/kitty), configured through a text file. Shift+Enter and notifications work without setup; set Option-as-Alt in its config for Option shortcuts.

WezTerm

A free, open-source, cross-platform terminal configured in Lua (wezterm.org). Shift+Enter works; use the bell setting above for alerts.

Warp

A terminal with its own built-in AI features (warp.dev). Shift+Enter works. Warp does not receive Claude Code's desktop notification, so use the bell setting or a Notification hook.

Running Claude Code inside tmux

Whatever the outer terminal, tmux needs a few lines in ~/.tmux.conf for Shift+Enter and notifications to get through:

set -g allow-passthrough on
set -g focus-events on
set -s extended-keys on
set -as terminal-features 'xterm*:extkeys'

When a terminal alone is not enough

Any of the terminals above runs Claude Code well. What they leave to you is everything around it: an editor to read the files it touched, a Git client to review and commit, and a way to keep several sessions and projects apart.

C2D Terminal is our answer to that, and you can use it next to the terminal you already have. It is a native macOS workspace where Claude Code runs in a real terminal (a genuine PTY with your own shell, dotfiles and PATH), with an editor, a file explorer and a Git panel in the same window. It is free and open source under the MIT license. It is younger than everything above, and there is no signed download yet, so you build it from source.
